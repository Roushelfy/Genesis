## What is actually matched

Each association checks the exact recovery mesh, native material/collider/URDF
assets or physical Shell pad geometry, actual per-environment mass, all declared
physical/solver parameters and byte-identical Genesis runtime inventory. Source
constructor syntax additionally fixes the Shell E/nu/density/thickness/damping
and native PCG cap, recovery model and body-source prior. Configured radius,
source reduction, dt, tolerances, precision, output, cadence and batch size
remain explicit. Changed radius, friction, timestep, mass or runtime signature
are rejected by15 negative controls; physical thresholds are unchanged.

Every timing uses its own successful audit, exact start/result/cost/journal
identities, complete requested observations and endpoint conformance. The
recorded0.5% tensor/1% raw-peak tests are numerical sensitivity controls, not
new continuum error intervals. A separate passing profile cannot admit a
failed timing. Full-output rows associate all nine measured metrics. Max-only
rows associate only raw Mises magnitude error; complete-field errors are not
assigned to unexported tensors.

Every-step memory uses12 separately admitted process profiles, with source/run
identities, sampled GPU peak, CPU max RSS, sample count and maximum sample gap
retained. Sparse memory cells stay empty. A sampled peak can miss a transient,
and neither endpoint allocation nor an every-step profile is relabelled as a
sparse or primary-timing memory measurement.
