## Conditional uncertainty and ties

The reference qualifier retains its predeclared sums of observed spatial,
time, contact, angular and depth changes. Ranking conservatively uses the product
of their1+changes, minus1, and additionally retains measured reference-norm
q9/q25 sensitivity. Method integration uncertainty is separate: absolute error
metric changes for fields/raw peaks, and actual peak sampling changes normalized
by the reference for common peaks. Fixed limits remain0.005 for field changes,
0.01 for peak changes and1e-9 relative agreement of a shared reference norm.

For measured relative error e, reference envelope d and method sampling change m,
the reported conditional interval is
`[max(e-m-d,0)/(1+d), (e+m+d)/(1-d)]`, requiring0<=d<1.
Only strict interval separation distinguishes a pair. Overlap and touching
intervals remain unresolved. This assumes the observed envelopes bound the
unresolved errors; it is not a statistical confidence interval or continuum proof.
The complete contract was fixed before the fine method results in
`meta/canonical-stvk-ranking-contract-v1.json`.
