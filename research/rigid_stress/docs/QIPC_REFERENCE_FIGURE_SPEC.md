# Figure contracts for the QIPC comparison

These are repository report figures in English, at183mm width, with editable
SVG/PDF,450dpi PNG and150dpi inspection previews. No venue-specific submission
claim is made. Use the existing academic-workflow Matplotlib helper in
`shell_comparison/nature_mpl_style.py`; retain source identities and raw data.

| Claim anchor | Figure and panel roles | Evidence / material passport | Qualification |

Data are paired deterministic trajectories, not independent statistical samples.
Show every timing repeat or its observed range, without a statistical confidence
interval. Use time-series lines for ordered histories and scaling; use shared
scalar maps for material fields. Do not use bars that hide repeated measurements,
fit a footprint, or convert a failed reference prefix into a complete trajectory.

The figure captions must state units, scopes, source revisions/patch variants,
sampling domain and unresolved qualifications. Report strongest/weakest regions
and supported implications from the generated data, with separate body-text
interpretation. Inspect actual PNG/PDF exports before calling a figure final.
