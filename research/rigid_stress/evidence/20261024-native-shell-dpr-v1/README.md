# Native shell DPR publication evidence

Compact records for the 2026-10-24 native thin-shell delivery. See the report
`../../docs/SHELL_DPR_NATIVE_20261024.md` and running guide. The primary timing
source is 50a8e3bf3. `metadata/measurements-final.json` preserves repeat timings,
invalid counts, memory, configuration identities and intrusive trace summaries.
The trace step denominator counts CPU annotation scopes only; GPU annotation
spans are not additional steps.

Controls include numerical and independent physical comparisons, complete
Franka history, full-field audits, regression receipts and retained FP32
rejection. Earlier failed/unsubmitted attempts remain in the campaign ledger.
The two missing-pyfe3d attempts were replayed with a pinned isolated data
overlay. Raw physical availability records inherit an old OpenSees note from
the CPU study: this is historical, not a current installation probe or an
executed OpenSees reference. Current pyfe3d/Code_Aster probes are distinct.

`manifest.json` hashes every copied source and references full source inventories,
large benchmark JSON, field arrays and traces on data. Those external files
are retained in place. Small condition-bank and result metadata are publication
deliverables; runtime arrays, dependencies and logs remain under data.
