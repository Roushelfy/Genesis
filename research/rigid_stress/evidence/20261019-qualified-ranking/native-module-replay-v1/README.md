# native-module-replay-v1

Four admitted numerical B8 module replay modes, complete1200-frame histories,24 resident input buffers, actual stress reset schedule and three warm timing repeats on one GPU. Original scene recording, archival and independent validation are outside timing. Module time includes input restoration and native recovery/acceptance, not dynamics. Physical errors and production motion admission are separate unresolved claims.

Large JSON and raw logs use deterministic gzip. Decompression preserves every original byte; the manifest records both encoded and original SHA-256/size. Use `python -m gzip -d FILE.gz` on a separate working copy to inspect those records. Full trajectory/source-history NPZ files remain on data with exact identities.
