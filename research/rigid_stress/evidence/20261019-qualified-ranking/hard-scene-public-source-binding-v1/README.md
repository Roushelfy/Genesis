# Public source bindings for the Hertz scene campaigns

Exact public Git source bindings for the original and selected moving-scene engines. Public task commits aa803cdb9 and d4503b9e4 match every captured scientific file in nine source inventories; d4503b9e4 also matches the five explicit regression-test dependencies. Local isolated commit identities are retained unchanged as execution provenance. Research workers use their separately captured versions. This is reproduction evidence, not additional physical or numerical accuracy.

For public replay use baseline `aa803cdb9e88da9e738ee156d5ebfb1fe952f950` or selected `d4503b9e42a7f8f8555d128b437bb45b3193cf75`, both reachable from `rigid-stress-recovery`. The selected scientific bytes match isolated local commit `900110f112c9d1313ebac9b3d75ef076ad7e197d`; its different commit ancestry need not be fetched or recreated. This binding supplements the original provenance receipts in `hard-scene-transfer-v1` and `hard-scene-large-batch-v1` without rewriting either packet.

In a fetched repository run the included stdlib verifier with `--revision` set to the public commit, one or more decoded `--source-inventory .../source.json` paths, optional decoded `--test-receipt .../hard-scene-terminal-v1.json`, and a fresh explicit data-side `--output`. The verifier accepts gzip inventories as well. Then create a clean sparse checkout of the public commit, retain the captured research workers and original conditions, and map recorded checkout/output paths into new explicit data directories before submitting. Live hollow-shell scientific outputs are not included here.
